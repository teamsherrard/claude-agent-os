# Tool map — every editing job → the Riverside call

One page: what a video editor does, and the exact connector tool that does it here. **Every entry is a real tool on the Riverside connector** (verified against the connector's own editing guide, September 2026). The full recipes live in `${CLAUDE_PLUGIN_ROOT}/shared/riverside-playbooks.md`.

| Job | The Riverside call |
|---|---|
| Find the video | `platform_list_recordings` (status must not be `uploading`) → `platform_get_recording` → `platform_get_project` (recordings + edits in one call). Search by spoken words: `search_riverside` / `search_recording_transcripts_exact`. |
| Get the video in | **Not via the connector.** The main recording is recorded in Riverside or uploaded in the Riverside dashboard. The connector's `media_create_media_upload` → `curl -T` → `media_finalize_media_upload` handles B-roll / music / images / logo only (≤500 MB each; MP4/WEBM/MPEG, WAV/MP3/OGG, JPG/PNG); when no shell is available (Cowork), the agent drops the file into Riverside's media panel and `media_list_media` finds it by name. |
| Make the working copy | `editing_create_edit_from_recording` (sessionId = recording id, projectId, title) → `editId`. Not gated on Grow (live-tested); if it ever returns `FAILED_PRECONDITION`, fall back to an edit the agent creates in Riverside, found via `platform_list_edits`. Snapshot before destructive work, and the cut-only master for reels: `editing_clone_edit`. |
| Read the transcript (free) | Prose for understanding: `platform_get_transcript(sessionId)`. Cut-grade: `editing_read_aligned_transcript(editId, includeParalinguistics:true)` → compact rows with `spanId`, `playableStartMs/EndMs`, plus the emotion events; `detail:"words"` in a window for `wordId`s and source-time `assetStart`. |
| Cut a passage | `editing_resolve_transcript_selection(intent:"remove", boundary_range start/end text anchors)` → execute the returned `cut_time_ranges` payload unchanged, against the same revision. |
| Filler words | `editing_remove_fillers(method:"Cut")` — transcript-labelled, no audio synthesis exists. Undo: `editing_restore_audio_cleanup(cleanup:"fillers")`. |
| Dead air | `editing_remove_pauses(thresholdMs)` — 1500 long-form, 1000 reels, 800 trailer. Undo: `restore_audio_cleanup(cleanup:"pauses")`. |
| Bloopers, retakes | Riverside's own AI retake flags: the recording clip's `comments[]` (`source:"ai"`, source-time ranges) from `read_timeline_in_range`, read against the words, then the resolver (`clean-cut.md`). |
| Audio enhance | `editing_set_magic_audio(trackId, enabled:true, mixLevel)` — 0.70 default, 0.85 phone/echoey, on every speaker track. Read `trackId` from `editing_read_timeline_in_range`; read the keyframe back. |
| Colour grade | `editing_set_color_correction(target track, {brightness, contrast, saturation, colorTemperatureKelvin})` — the visible-but-natural values in `footage-look.md` (+0.04 / +0.12 / +0.08 default). |
| Reframe to 9:16 | `editing_batch` op `update_aspect_ratio {ratio:"9:16"}` **BEFORE any overlay exists** (refused afterwards — clone from the cut-only master), then `editing_apply_smart_layout(style:"FullScreen")`. Face offset: batch `update_scene_slot_settings {sceneId, updates:{<tileId>:{trackId, positioning:{scale:1.0, offset:{x,y}}}}, overwrite:true}`. |
| Karaoke captions | `editing_set_captions(editId, show:true, position:{x:0.5,y:0.84}, style:{animation:{effect:"karaoke"}, contentPerSegment:"lines_1", effect:"outline", fontFamily:"Poppins ExtraBold", fontWeight:800, fontSize:84, primaryColor:"#FFFFFF", secondaryColor:<brand accent>, textAlign:"Center", widthRatio:0.8})`. Long-form: `set_captions show:false` (mandatory). Inside a batch: `update_global_caption_settings {captionsJson:"<JSON string>"}`. |
| Proper-noun spelling | **No transcript-edit tool.** Captions render from Riverside's transcript as-is. Check the aligned transcript; if the agent's name / brokerage / city / address is wrong, they correct it in the Riverside transcript panel (free, one minute) BEFORE captions. |
| Hook banner / emphasis pop-up / CTA banners / icons | Kit v3 overlay: `editing_insert_overlay(assetId, startMs, durationMs)` → batch `modify_scale {clipId, time 0, scaleW:W, scaleH:H, canvasWidth:W, canvasHeight:H}` + `set_overlay_clip_animations {clipId, inAnimation:{animationType, duration:{n,d}}, outAnimation:{…}}` → words as one `insert_text_overlay` (`effect:"shadow"`) → `modify_position` into the zone. CTA banners: words baked, nothing on top; primary on the closing ask to the last frame, `cta_pack` variant on each other spoken ask (`cta-pack.md`). Native fallback: batch `insert_text_overlay {role:"TITLE", effect:"boxed", …}` → the result's `data.clipId` → `modify_position` to the format zone. |
| Name strip (lower third) | The kit's `lower_third` overlay (same recipe as above), or `editing_add_lower_third(name, title, startMs, durationMs)` → it inserts centred on the face → batch `modify_position {clipId, time 0, positionX:200, positionY:305, canvasWidth:640, canvasHeight:360}`. |
| Zooms (punch-in, step-back, jump-cut cover) | A zoomed SCENE, not a keyframe (LIVE-TESTED): batch `split_scene_at_time` at the beat's first word and the first word after it (source time) → read the new scene's id and tile → batch `update_scene_slot_settings {sceneId, updates:{<tileId>:{trackId, positioning:{scale:1.06|1.10|1.14, offset:{x:0,y:0}}}}, overwrite:true}`. Hard-cut zoom on phrase boundaries; the step-back holds 1.10 and cuts OUT to 1.0; the jump-cut cover is a 1.0↔1.06 change on one side of every editorial cut (`effects-menu.md`). `modify_scale` on a recording track or clip returns success and writes nothing. Swoosh only if `sfx.swoosh_media_id` exists → `editing_insert_audio` at the beat's PLAYABLE ms. |
| Transitions / SFX | **Not exposed.** Riverside's hard cuts are clean; energy = zooms, cut covers, animated entrances (+ an uploaded swoosh). Section sound = a 1.8 s slice of a free `transition` track (`music.md`). Say so in the delivery, don't fake it. |
| B-roll (stock) | `editing_get_stock_media(query with daytime words, mediaType)` → `editing_insert_stock_media(externalSourceId, mediaType, startMs, durationMs, position)` → batch `modify_scale` the new overlay CLIP to the canvas (full-cover). Never a clip darker than the speaker's shot. |
| B-roll (own footage) | media upload (or the agent drops it into Riverside's media panel) → `editing_insert_overlay` (image/video) → full-cover scale at time 0. Listing stills: full-cover for 3–4 s, a hard cut or a 0.15 s `fadeIn` entrance from `set_overlay_clip_animations`; never a hand-written mid-clip keyframe (it hangs the editor). |
| Split-screen (horizontal b-roll on vertical) | batch `change_layout {layoutId:"solo-half-vertical-side-1-tile-portrait", sceneIds}` (speaker top 50%) + the b-roll overlay positioned at `y=3/4`, scaled to the lower band. |
| Music bed + stingers | `editing_get_stock_music(collection, section:"underscore")` → `editing_insert_audio(assetId, startMs:0, dB:-18 reel / -22 long-form, fadeInMs:800, fadeOutMs:1500)`; long-form stingers: `get_stock_music(section:"transition")` → `insert_audio(assetId, startMs:<section start>, durationMs:1800, dB:-12, fadeOutMs:600)`. Ducking is not a tool — a static bed is the safe default. |
| Logo | batch `insert_logo {assetId, placement:"topRight", opacity:0.7, width:{n:1,d:8}}`; if a logo already exists, `replace_logo {assetId}` (`insert_logo` fails then). `editing_apply_brand` also applies the studio kit's captions preset and intro/outro — setup-time only, never inside a pass. |
| Section map + markers | The Studio writes the **section map** (playable `00:00` timestamps + plain notes) for the YouTube System and places navigation markers named by the first spoken words with batch `add_chapter {time, title}` / `move_chapter {chapterId, newTime}` (markers cannot be renamed or deleted). It never names a chapter. |
| Verify a pass landed | Every write returns a `revision`. `editing_compare_revisions(editId, fromRevision, toRevision)` lists the cuts/mutes/toggles/scenes that changed, with the feature that made them. `editing_get_revision` = cheap staleness check. |
| Snapshot / undo | `editing_clone_edit` before the first destructive pass (only when the recording exists nowhere else); `restore_audio_cleanup` for fillers/pauses/smart mutes; `delete_clip` by id; the agent's own undo in the Riverside editor. |
| Export | `exports_create_export(sourceEditId, composeSettings:{export:{quality:"1080p", fileName}}, creationSource:"web")` → poll `exports_get_export(id)` until `COMPLETED`. **Returns an S3 key, not a download link** — the agent downloads from Riverside. |
| Frame-QA | Ladder in `frame-qa.md`: (1) the downloaded export via ffmpeg, (2) the editor preview scrubbed to timestamps in a signed-in browser (Chrome extension, or the app's own browser in Cowork), (3) the raw recording, (4) rule-based + the agent's eyeball. |
| Publish | `social_get_connected_platforms(studioId)` → `social_get_publishing_guidelines` → `editing_get_export_publish_data` (YouTube Content-ID check) → **explicit confirmation** → `social_upload_create` → `social_get_upload_status` once. Scheduling via `scheduledAt`; a scheduled post can still be changed with `social_update_upload` or cancelled with `social_cancel_upload` before it goes out; a published post cannot. |
| Query ceiling | None documented. The constraint is **optimistic locking**: pass `expectedRevision` from your last read on every write; `CONFLICT` → the one rule in `house-rules.md`. |
| Credits | No credit meter. `FAILED_PRECONDITION` = a feature gate or a missing precondition (no transcript yet, still processing) — explain it, don't retry blindly. |

## Things that are simply not there (say so, don't pretend)

- `reorder_timeline`, `create_edit_from_segments`, the `keep` / `move` intents — unavailable. The clip-move ops exist in the batch surface, but a re-ordered talking head needs a human ear on the joins, so the Studio does not rearrange speech: rearranging = cuts only (or the agent does it by hand).
- Transitions, a sound-effect library, count-ups, eye contact (exists as `modify_eye_correction` but is a banned heavy-AI effect here), background removal (`modify_background` — banned on a talking head).
- A download URL for an export. The agent clicks Download in Riverside.
- Transcript word correction from the connector.
- Renaming or deleting a chapter marker.
