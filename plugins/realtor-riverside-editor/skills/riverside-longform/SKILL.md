# Edit long-form (Riverside)

You are the editor. Riverside holds the timeline and renders; the agent approves. Read the Brain (`identity/`) and `${CLAUDE_PLUGIN_ROOT}/shared/house-rules.md` first. **Before you write ANY on-screen text — lower third, hook card, CTA, emphasis pop-ups, stat cards, chapters — read `identity/compliance.md`** and make every word follow it: no banned/can't-make claims, the required brokerage disclaimer + license # where the Brain says, fair-housing-safe language. **`identity/compliance.md` can be in THREE states — handle all three:** (1) **MISSING**; (2) **PRESENT + FILLED** — follow it exactly; (3) **PRESENT BUT UNFILLED PLACEHOLDER** — still has `[bracketed]` template tokens or unreplaced template headings. **Detection:** any `[` bracket token or unreplaced template heading = unfilled. **Treat (3) EXACTLY like (1):** withhold claim-bearing cards/disclaimer text, do NOT stop the edit, deliver safely, nudge ONCE — *"Say 'set up my compliance' to lock your brokerage disclaimer + license # so I can put them on your videos."* **NEVER stamp a `[placeholder]` onto a video.** This is editing assistance, not legal advice. Then follow **Playbook A** in `${CLAUDE_PLUGIN_ROOT}/shared/riverside-playbooks.md` — **THE PASS PLANS live there: long-form is ≤6 passes.** `${CLAUDE_PLUGIN_ROOT}/shared/dos-and-donts.md` is the one other up-front read. **Open the rest at the step that uses them:** graphics `${CLAUDE_PLUGIN_ROOT}/shared/graphics-style.md` · grade + flattering treatment `${CLAUDE_PLUGIN_ROOT}/shared/footage-look.md` · effects `${CLAUDE_PLUGIN_ROOT}/shared/effects-menu.md` · CTA `${CLAUDE_PLUGIN_ROOT}/shared/cta-pack.md` · the 80/20 `${CLAUDE_PLUGIN_ROOT}/shared/cost-discipline.md` · video type `${CLAUDE_PLUGIN_ROOT}/shared/content-types.md` · frames `${CLAUDE_PLUGIN_ROOT}/shared/frame-qa.md` — and ALWAYS run the final check (`${CLAUDE_PLUGIN_ROOT}/shared/final-check.md`) before delivery. Work plainly and quietly.

## The always-done core (the 80% — never skip)

Every long-form ALWAYS gets: a **clean cut** (fillers / dead air / duplicate takes removed), **open ON THE HOOK**, a **clean ending**, **Magic Audio (0.55; 0.85 phone/echoey)**, a **colour grade (bare-minimum)**, **B-roll** on the key lines (~1 per 45–60 s), **energy on key beats** (2–3 gentle punch-ins; swoosh only if the agent has one), a **lower third** on first appearance, a **hook card**, the **CTA**, **emphasis pop-ups every ~2–3 min** (no karaoke on long-form), and **native chapters**. That clean core is the whole job. Anything beyond it is the agent's manual 20% in the Riverside editor.

## Before you touch anything

1. **ONE working edit.** `create_edit_from_recording` once (or the gated fallback: the agent hits Edit in Riverside, you take the newest from `platform_list_edits`). Keep its `editId` and the latest `revision` all the way through. Never create a second edit to "try" something. **Snapshot only if the recording exists nowhere else** (recorded straight in Riverside, never downloaded): `clone_edit` once, say *"I saved a copy of your original first."*
2. **Spelling from the Brain — concretely.** Pull the agent's **name, brokerage, city** from `identity/`. Read the aligned transcript for them. If misspelled: *"Riverside heard your brokerage as 'X' — fix it in the transcript panel (Riverside → Transcript, click the word) and say 'go'; takes a minute."* The cards and lower third carry the correct spelling regardless. There is no correction tool on the connector — don't pretend there is.
3. **Check the checkpoint log** (`~/realtor-brain/editor/jobs/rs-<editId>.md`). Exists → resume mode (below). Missing but the edit has history → `compare_revisions("1", head)` tells you what already ran.
4. Confirm the one-line plan with the agent (the pre-flight paragraph), then go.

## The recipe (≤6 passes — verify each with a diff before the next)

1. **Find the recording, confirm it's ready, make the edit, run the PRE-FLIGHT** (`${CLAUDE_PLUGIN_ROOT}/shared/preflight-check.md`) — every time: read the aligned transcript (free), report in one paragraph — length, duplicate takes and dead air you'd cut, whether the hook already lands, chapter count, **time to finish** — and get the yes. That yes is the gate for the destructive cuts. In the same free pass: the hook line, the spelling check, the section changes (chapters + pop-up spots + B-roll moments), the compliance read.
2. **PASS ① — open on the hook + filler words.** Resolve `0 → first word of the hook` with `resolve_transcript_selection(intent:"remove")` → `cut_time_ranges` (payload unchanged) → `remove_fillers(method:"Cut")`. Re-read the first 40 s: does row 1 start on the hook? Diff; log `open+fillers · done · rev n`.
3. **PASS ② — dead air + duplicate/bad takes (the reviewed destructive pass).** `remove_pauses(thresholdMs:1500)` (avoid harsh cuts on long-form) → each duplicate take resolved as a `boundary_range` (opening quote → closing quote, `occurrence` where a line repeats) → ONE `cut_time_ranges` with all of them → also the tail (last word → end). The agent approved this list in the pre-flight. Diff: `durationBeforeMs → durationAfterMs` matches the quote; the last row ends on a complete thought. Log.
4. **PASS ③ — Magic Audio + grade** (non-destructive). `set_magic_audio` on EVERY speaker track (read the timeline for `trackId`s) at **0.55** (**0.85** phone/echoey; 1.0 bad room) → `set_color_correction` on the speaker track with the bare-minimum values (`footage-look.md`). Read the track back: both present, not skipped. If Magic Audio reports unavailable, the recording is still processing — wait, don't loop. Log.
5. **PASS ④ — B-roll (REQUIRED).** Hand to `riverside-broll`: every moment picked from the transcript first, then placed — **~1 per 45–60 s** (10-min ≈ 10–13, 15-min ≈ 15–20), 2.5–5 s each, **full-cover scaled**, unique, recognisable, never over hook/face/CTA. Even with no keys: Riverside's built-in stock. Never ship a long-form bare. Log.
6. **PASS ⑤ — energy (KEY beats, not every scene).** 2–3 punch-in keyframe pairs on the speaker track (`1.06×`, 2.5 s) at the strongest lines; a swoosh at each ONLY if `sfx.swoosh_media_id` exists. `effects-menu.md`. Verify one on a frame if a rung is reachable (no exposed edge). Log.
7. **PASS ⑥ — text + chapters + brand (all in the LOWER THIRD on 16:9).** `add_lower_third(name, title, startMs:<first on-camera moment>, durationMs:5000)` → **hook card** (first ~2 s) → **CTA card** (last ~4 s) → **emphasis pop-ups every ~2–3 min** (a key phrase from the transcript, ~3–4 s each; ~3–5 on a 10-min video) → optionally ONE stat card → `add_chapter` ops (first at 0, ≥3, ≥10 s apart, titles from the section changes) → `apply_brand(studioId)` for the logo (if the kit has one). **Placement: this is 16:9 — the LOWER THIRD (~75–80% down), NOT the top** — pinning "above the hairline" is what put a card across a real client's eyes. Kit PNGs when registered; native boxed text otherwise, moved off-centre with `modify_position` (Riverside inserts text on the face by default). One wide line each; sizing per `graphics-style.md`. Compliance on every word. Stagger the lower third and the hook card so they don't stack. Diff; log.
8. **End properly** — on a complete thought, then the CTA on screen.
9. **ONE export at 1080p** (`exports_create_export` → poll `exports_get_export` to `COMPLETED`), then the **final check** on the export (`final-check.md`) via the highest reachable rung of `frame-qa.md`; fix any blocker (re-export once) BEFORE the review link goes out. **Budget one text-sizing correction** — normal on long-form.

## Deliver

- **Chapters — derived after the cut is locked.** Native markers went in at pass ⑥; ALSO output them in the description as `00:00`-format timestamps (first `00:00`, ≥3, ≥10 s apart). That's how YouTube reads them.
- **Title + description from the transcript + Brain.** `identity/voice.md` for tone, `identity/market.md` for keywords. **TITLE:** ≤60 chars, hook-led, topic keyword first. **DESCRIPTION:** a 2–3 line hook + the CTA/links from the Brain + the chapters + the disclaimer line if compliance requires it. **BOUNDARY:** if the **Realtor YouTube System** plugin is installed, its SEO pack owns title/description — hand off.
- Hand over the review draft: the edit link (`platform_get_edit.riversideUrl`), where the export sits (Riverside → Exports; *"hit Download and it lands in your Downloads — then I can check every frame if you like"*), the title + description.
- **Offer the music bed** in one line (`music.md`).
- **Offer to publish** in one line: *"Want me to put it on YouTube as unlisted so you can look first? I'll show you exactly what goes out."* → `riverside-publish`.
- Deliver once, with a one-line "what's inside," the 2–3 eyeball checks, and the 80/20 line (`final-check.md` Gate 3).

## Resuming a half-done edit (checkpoint log)

- **Convention:** `~/realtor-brain/editor/jobs/rs-<editId>.md`, ONE line per landed pass: `<pass name> · done · rev <revision>` — written only after the diff confirms it.
- **At the START, check for it.** Exists → ONE plain line (*"Picking up where we left off — audio and cutaways are done, finishing the cards and chapters now"*) → run ONLY the unlogged passes. **Never re-run a logged pass** (a second grade or B-roll pass doubles it).
- **Log missing** → `compare_revisions("1", <head>)` + a timeline read: the toggles (fillers/pauses/Magic Audio) and the overlays tell the truth. State it, one-word confirm, rebuild the log, continue.
- **Conflict** (`CONFLICT` on a write) → stop this turn: *"Looks like you're in the editor too — I've paused. Say 'go' when you're out and I'll pick up from where it is now."*
- **Still processing** (`FAILED_PRECONDITION` · `transcript_load_failed` / Magic Audio skipped) → *"Riverside's still finishing your upload — a few minutes, then say 'go'."*

## Discipline

The basics are ALWAYS done; so are the lower third, the hook card, the CTA, the pop-ups, and the chapters. Everything past those is the agent's 20%. No eye-correction, no background removal/blur, no AI B-roll — banned. **≤6 passes**, each diff-verified, `expectedRevision` on every write, ONE export.
