## How skills read this file

**This file is optional, and its absence or emptiness is never an error.**

1. **A filled section is authority.** Where a section has real content, it **outranks** the generic
   guidance written into the skill. The skill's own instructions are the floor; the doctrine is the
   ceiling.
2. **An unfilled section is silent.** A heading with no body under it means *no doctrine on this
   yet* — the skill uses its own guidance and **says nothing to the agent about a doctrine file.**
   Never treat a heading as content. Never paraphrase a heading into advice.
3. **Never fill this file from inference.** Not from the other doctrine files, not from what a good
   agent would do, not from the web. It gets filled by Mike, in his words, or it stays empty.
4. **Never quote it as Mike's opinion unless it is written here.** Attributing generic best practice
   to a named person is the one failure mode this file must not create.
5. **Detection:** a section is unfilled if there is no prose between its heading and the next
   heading. The `⚠ STATUS: UNFILLED` banner at the top is removed by hand once real content lands.
